
 📊 Power BI Dashboard – Business Insights

This repository contains a Power BI dashboard built to analyze key business metrics and provide clear, interactive insights.

🔗 **Live Dashboard:**
[https://app.powerbi.com/groups/me/reports/e02d72d0-98d9-41c9-bd48-b1b16f11a8a2/75f1b8a8c40099d0b46c?experience=power-bi](https://app.powerbi.com/groups/me/reports/e02d72d0-98d9-41c9-bd48-b1b16f11a8a2/75f1b8a8c40099d0b46c?experience=power-bi)

 🚀 Overview

The dashboard showcases:

* Revenue & sales trends
* Category and region-wise performance
* Top/Bottom products
* Key KPIs with interactive filters

 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Data Modeling

 🎯 Purpose

To transform raw data into meaningful, easy-to-understand insights for faster decision making.
